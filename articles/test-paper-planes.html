How to test paper airplanes scientifically

Useful experiments separate design changes from throw-to-throw randomness.

Define one metric

Distance, hang time, accuracy and consistency are different objectives. Write the primary metric before the first flight and define how it will be measured.

Control the environment

Use the same space, launch direction and start line. Indoor testing reduces wind but moving people, open doors and ventilation can still disturb light aircraft.

Repeat every configuration

One dramatic flight can be luck. Run several trials and keep failures rather than silently discarding them. The average is useful, but the spread matters too.

Change one variable

If a plane dives, do not bend the trailing edge, widen a wing and add nose mass before the next throw. Make one adjustment and test again so the result has diagnostic value.

Record enough to reproduce

Paper type, dimensions, model name, configuration change, trial number and result are enough for a useful notebook. Reproducibility matters more than collecting large amounts of unstructured data.
