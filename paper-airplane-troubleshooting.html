A plane that turns, dives, stalls or varies is giving you a clue. Start with the repeated symptom, inspect the simplest causes in order, then change one variable and run the same launch again.

Persistent turn

It keeps turning left or right.

A repeated turn often begins with unequal geometry or biased launch direction. Do not add weight until those causes are checked.

  1. Compare left and right wing angles from the front.
  2. Sight down the center fold for body twist.
  3. Compare both trailing edges before adjusting trim.
  4. Repeat from the same release direction.
First controlled testCorrect one visible asymmetry only. Make five launches from the same line and compare the spread.

Immediate dive

It dives soon after release.

A crushed nose, mismatched wing angle, excessive downward trim or launch angle can all create a similar symptom.

  1. Inspect the nose for soft or crushed folds.
  2. Compare both wing angles and wing roots.
  3. Flatten excessive downward trailing-edge trim.
  4. Repeat a level, moderate launch.
First controlled testRebuild with fresh paper only if damage is visible. Keep design and launch unchanged.

A consistent fresh-paper baseline can separate material damage from geometry.

Climb then drop

It climbs, slows and stalls.

Treat this as a pitch problem to investigate—not proof of a single cause. Upward trim, mass distribution and launch angle interact.

  1. Check for excessive upward trailing-edge trim.
  2. Leave mass distribution unchanged for the first test.
  3. Use the same release angle and effort.
  4. Reduce one trim input, then repeat.
First controlled testMake one small trim correction and run five launches. Do not move weight during the same comparison.

High variation

Every throw behaves differently.

Reduce launch noise before blaming the plane. A comparison is only useful when the release is reasonably repeatable.

  1. Mark one launch line and one release direction.
  2. Use the same thrower and similar effort.
  3. Record every throw, including poor ones.
  4. Judge the average and range—not the best flight.
First controlled testRun five untouched baseline throws. If the spread stays wide, standardize the launch before changing the plane.

Use one paper pack when material consistency is part of the test.
